# OLP v11.1 Academic Library

## Included
- Resource Centre: Class / Level -> Subject -> Year professional library grouping.
- Bulk resource upload: select multiple files in one operation.
- Automatic year detection: exactly one 4-digit year (1990-2100) in a filename is used; otherwise the selected fallback year or "Year not identified" is used.
- Student Resource Centre: reads only resources assigned to the student's active classes through the existing `class-resources` Edge Function and uses server-issued signed URLs.
- Exams and Assignments: existing Class -> Subject navigation now shows the class academic year consistently for teacher/platform-owner and student views.
- Login: Show/Hide password controls for sign-in, sign-up, confirmation and password recovery forms.

## Safety
- No database migration is introduced by v11.1.
- No Edge Function is changed or deployed by this package.
- Existing exam/assignment business logic and marking workflow are retained.
- Production `main` should not be changed until the `v11.1-academic-library` Cloudflare preview builds and passes functional testing.

## Test checklist
1. Cloudflare preview build succeeds.
2. Sign in: show/hide password works.
3. Resource Centre teacher/owner: single upload still works.
4. Resource Centre teacher/owner: select 2+ files; year-bearing filenames group under the detected year.
5. Resource Centre: ambiguous/no-year filename uses selected fallback year or Year not identified.
6. Student: only assigned class resources appear and open/download works.
7. Exams: class, subject and academic year presentation is correct; open existing exam.
8. Assignments: class, subject and academic year presentation is correct; open existing assignment.
9. Mobile check.
